# 🍽️ Restaurant Performance Analysis (Swiggy Dataset)

This project performs a comprehensive analysis of restaurant data (from Swiggy) to uncover insights related to ratings, pricing, delivery time, and food types across different cities and areas.

## 📁 Project Structure

- `Swiggy.sql` – SQL queries for data analysis
- `swiggy.csv` – Dataset containing restaurant details
- `Restaurant Performance Analysis.docx` – Report/documentation of the analysis
- `README.md` – Project overview

## 📊 Dataset Overview

The dataset includes:
- Restaurant name
- City & Area
- Food type
- Price
- Ratings
- Total number of ratings
- Delivery time

## 🛠️ Technologies Used

- SQL (for data querying)

## 🔍 Problem Statements Solved

1. Retrieve all restaurant details sorted by highest rating.
2. Count the number of restaurants in each city.
3. List all unique food types available in the dataset.
4. Find the total number of restaurants in each area.
5. Identify the top 10 most popular restaurants based on total ratings.
6. Find the average price of a meal in each city.
7. Identify the most expensive and cheapest restaurants in each city.
8. Find the average delivery time per city.
9. Identify which city has the fastest and slowest average delivery time.
10. Check if higher-priced restaurants have better ratings.
11. Find the top 5 food types with the highest average ratings.
12. Identify the top-rated restaurant in each city.
13. Find restaurants where the price is above the city’s average price.
14. Analyze how food type influences delivery time.
15. Identify areas with the highest concentration of highly rated restaurants.
16. Determine if expensive restaurants receive more orders based on total ratings.
17. Rank cities based on restaurant availability and average ratings.
18. Find restaurants that have both high ratings and fast delivery times.

## 📈 Insights & Outcomes

- Cities with the best and worst delivery times
- Price vs. rating correlation
- High-demand areas for specific food types
- Strategic areas for new restaurant openings based on ratings and competition
