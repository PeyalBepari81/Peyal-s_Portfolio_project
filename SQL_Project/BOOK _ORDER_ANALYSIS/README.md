📚 Bookstore Data Analysis (SQL Project)
🧾 Project Overview

This project focuses on performing data analysis on a bookstore database using SQL.
The goal is to extract actionable insights related to sales performance, customer purchasing behavior, and inventory management.
It demonstrates the use of SQL queries, aggregations, and joins to answer real-world business questions from raw data.

🗂️ Project Structure
File	Description
Books.csv	Contains book information such as titles, authors, prices, and genres.
Customers.csv	Contains customer demographic details like name, country, and city.
Orders.csv	Contains purchase transactions and order details.
BOOK_ORDER_ANALYSIS.sql	SQL script containing all basic and advanced queries.
💡 Key Insights

Identified top-selling books and best-performing genres.

Analyzed customer purchase behavior across different regions.

Calculated total revenue and monthly sales trends.

Determined authors contributing the most to total sales.

Found stock levels and inventory requirements based on sales data.

🛠️ Tools & Technologies

Database: PostgreSQL

Language: SQL

Environment: pgAdmin 

🧠 Learning Outcomes

Strengthened understanding of data relationships using SQL joins.

Practiced data cleaning and transformation in SQL.

🚀 How to Use

Clone this repository to your local system.

Import all .csv files into a PostgreSQL database.

Execute queries from BOOK_ORDER_ANALYSIS.sql in your SQL editor.

Review the results and insights for further analysis or reporting.
