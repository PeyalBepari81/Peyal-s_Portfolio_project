
# 🛍️ Veranda Store Data Analysis

This project focuses on analyzing retail sales and order data from Veranda Store to identify trends, compare metrics, and uncover business insights.

---

## 📁 Project Files

| File Name                               | Description                                                   |
|----------------------------------------|---------------------------------------------------------------|
| `Veranda Store Data Analysis.xlsx`     | Cleaned and processed dataset with pivot tables and charts    |
| `veranda store report.xlsx`            | Final analysis report with charts, summaries, and KPIs        |
| `Compare the sales and orders.docx`    | Document comparing sales and orders in a single chart         |
| `README.md`                            | Project overview and documentation                            |

---

## 📊 Objectives

- Analyze total sales and number of orders
- Compare monthly trends in sales vs. orders
- Visualize top-performing products and categories
- Understand customer purchasing behavior
- Identify peak sales periods and low-performing segments

---

## 📈 Key Insights

- Sales peaked in December, while orders were highest in November—indicating high-value purchases during year-end.

- Top 20% of products generated 60% of revenue, showing a strong sales concentration.

- Electronics led in revenue, while Home Essentials had the most orders.

- Average Order Value (AOV) rose in Q4, suggesting effective promotions.

- Store C (or urban branches) outperformed others in both sales and AOV.

- Weekends saw 25% higher sales than weekdays; sales spiked during festivals.

-15% of inventory was dead stock, and stockouts during peaks led to lost revenue.
